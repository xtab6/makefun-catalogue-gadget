CHRONOTOAST Model CT-1 — a catalogue photograph of an impossible gadget: a polished chrome toaster whose slots pop golden toast slices shaped like clock faces, with a small analog clock dial on its side and a butter dish as the single accessory. Shot as a studio product photo on a seamless warm-grey backdrop with a pedestal, soft floor shadow, and a catalogue caption bar. Toasts yesterday's bread, tomorrow.

## Run it

```sh
python3 main.py
```

`main.py` copies `assets/entry.jpg` (rendered deterministically by `render.py` with Pillow) to `/output/entry.png`, verifying magic bytes, size, and a byte-identical copy.
